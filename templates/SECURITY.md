# Security reporting and scope

This is a restricted prototype. No clinical decision-making or public data service is authorized by the code or documentation alone. Specify a responsible security contact before a pilot.

Trust model: honest protocol participants and trusted local endpoints; curious coordinator plus explicit integrity checks. Signatures do not prove truthful counts or malicious-secure key generation. Output leakage and irreversible partial release remain.

Store no patient rows or keys in this repository. Report issues using synthetic reproductions and sanitized logs. Do not attach patient workbooks to tickets. A critical consent/key/integrity failure blocks the pilot and requires fresh keys after remediation.
