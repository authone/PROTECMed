# PROTECMed developer package v2

Start with [README_START_AICI.md](README_START_AICI.md) for the Romanian handover, then [IMPLEMENTATION_BLUEPRINT.md](IMPLEMENTATION_BLUEPRINT.md) for the English normative specification.

This package contains documentation and reference helpers, not completed application services or an installer. The mandatory scope is exact local cohort counts with OpenFHE and unanimous 2/2 or 3/3 decryption. Read [CHANGELOG.md](CHANGELOG.md), [AGENTS.md](AGENTS.md) and [verification/verification.json](verification/verification.json) before implementation.

The restricted clinical aggregate regression appendix must not be published automatically. No patient-level rows or private keys are included.
